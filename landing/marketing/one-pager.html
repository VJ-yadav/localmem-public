localmem.org

The problem in 30 seconds

Every AI tool ships with its own memory. ChatGPT forgets what you told Claude. Cursor forgets what you discussed in ChatGPT. Even within one tool, memory is project-scoped, with no semantic search, no time model, no audit trail. The cloud memory layers exist (Supermemory, mem0, Zep) but hold your data in their cloud, in their format, behind their pricing. The local-first option had not been built. localmem is that option.

How it works

1. Append-only event log

~/.localmem/events.jsonl is the single source of truth. Every write, fact, forget, supersede is a line in this file. cat-able forever.

2. Three derived caches

DuckDB (bitemporal facts), LanceDB (BGE-small vectors), Tantivy (BM25). All rebuildable from the event log via localmem replay.

3. MCP-native surface

6 tools, 2 prompts, 4 resources exposed via the Model Context Protocol. Every MCP-aware AI client picks them up.

Get started in 60 seconds

  1. Install the core binary (macOS Apple Silicon prebuilt; Linux + Intel Mac build from source): 
    curl -fsSL https://localmem.org/install | sh
  2. Initialize + start: 
    localmem init && localmem fetch-model && localmem serve &
  3. Wire into your AI tool: 
    localmem mcp install --client claude     # or claude-code, cursor, cline, windsurf

Restart the AI client. The agent now has memory_write / memory_search / memory_recall tools. That's it.

Who this helps

Devs using 2+ AI agents

Stop re-explaining conventions, preferences, and project facts to every new session. Write once, every wired agent reads it. Walkthrough: localmem.org/repo → docs/SHARED_MEMORY_FOR_AGENTS.md

Teams with shared tribal knowledge

Per-project --home scoping keeps client work isolated from personal memory. Each repo can have its own .localmem/. No leaks.

Anyone who wants an audit trail

localmem audit <fact-id> traces every event, journal entry, and follow-up that touched a fact. No black boxes. No "the AI just decided."

Privacy-conscious developers

Zero content telemetry, ever. Your captures stay on disk. No phone-home. The local-first promise is verifiable: cat events.jsonl shows you everything.

v0.2.0 platform support: macOS Apple Silicon ships as a prebuilt binary. Intel Mac, Linux x86_64, and Linux aarch64 work today by building from source. Windows planned for a future release. Cross-compiled binaries for everything except Windows ship in v0.2.1.
