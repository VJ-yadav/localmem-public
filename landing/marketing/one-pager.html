localmem.org

your agent's memory, written to a file you own.

A local-first memory layer that any MCP-compatible coding agent can read and write. Single static Rust binary. No content ever leaves your machine.

How it works
01 // truth
Append-only event log.

~/.localmem/events.jsonl is the single source of truth. Every write, update, forget, supersede is one line. cat-able forever.

02 // caches
Three derived stores.

DuckDB (bitemporal facts), LanceDB (BGE-small vectors), Tantivy (BM25). All rebuildable from the log via localmem replay.

03 // surface
MCP-native, 6 tools.

memory_write, memory_search, memory_recall, memory_profile, memory_forget, memory_journal. Plus 2 prompts and 4 resources.

Install in 60 seconds
1
Install the binary.
$ curl -fsSL https://localmem.org/install | sh
One static Rust binary · macOS Apple Silicon prebuilt · Linux + Intel Mac build cleanly from source.
2
Initialize and start the core.
$ localmem init && localmem fetch-model && localmem serve &
Creates ~/.localmem/ · fetches the 30 MB embedder once · binds 127.0.0.1:8765.
3
Wire up any MCP-compatible agent.
$ localmem mcp install --client claude $ localmem mcp install --client claude-code $ localmem mcp install --client cursor $ localmem mcp install --client cline $ localmem mcp install --client windsurf $ localmem mcp install --client codex
Restart the client. The 6 memory_* tools appear automatically.
The local dashboard
Visual browse over your memory.

Subjects, tags, recent captures, search, recall, synthesized profile. Switch between project-scoped stores live. Read-only, single-user, runs on localhost:8088. The Rust core can also serve this directly via localmem serve --dashboard (planned, v0.2.2).

$ python3 dashboard/serve.py # proxies /api -> 127.0.0.1:8765 # discovers every .localmem/ on disk # browser opens at: http://localhost:8088/
