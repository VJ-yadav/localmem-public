Core is not reachable right now

  
The dashboard's proxy is up, but the supervised localmem serve subprocess isn't responding at /api.

  
Usually this means the core died after a store-switch failed, or the localmem binary isn't on your PATH.

  
Most likely fixes

  
    
    
  1. Is the localmem binary installed? which localmem should print a path. If not, install via curl -fsSL https://localmem.org/install | sh.
    2. 
    
  2. Was the binary started by this dashboard? If you started localmem serve yourself in a separate terminal, that's fine. Stop the duplicate before retrying.
    3. 
    
  3. Restart the dashboard. Ctrl-C the python3 dashboard/serve.py process and restart it. It will spawn a fresh localmem serve subprocess.
