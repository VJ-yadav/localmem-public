Can't reach the localmem core

  
The dashboard talks to your running localmem serve at http://127.0.0.1:7788. It looks like that's not reachable right now.

  
Three things to check

  
    
    
  1. Is the core running? Open a terminal and run localmem serve. Leave it open. Then refresh this page.
    2. 
    
  2. Are you opening this from file:// or a non-localhost URL? Browser CORS rules block fetches across origins. Fix: serve this directory from localhost too. From the dashboard/ directory: python3 -m http.server 8080, then open http://localhost:8080/.
    3. 
    
  3. Different port? If your localmem serve --addr uses a non-default port, set the endpoint in the URL: ?api=http://127.0.0.1:9999.
    4. 
  

  
A future localmem serve --dashboard will serve this UI on the same port as the core API, no CORS issues. Tracked for v0.2.1.
